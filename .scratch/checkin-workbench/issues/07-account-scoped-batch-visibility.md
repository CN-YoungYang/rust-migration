# 07：按签到账号归属隔离批次可见性

**要构建的内容：**

修正管理员代替多个用户发起签到批次时的权限边界。普通用户可以看到与自己拥有的签到账号相关的批次，但只能看到自己的批次项和裁剪后的批次汇总；恢复整批执行会影响其他账号，因此只能由管理员或仍拥有整批账号的批次创建者执行。

- [x] 批次详情只返回普通用户当前拥有的签到账号及其结果，不泄露其他用户的范围和汇总数量。
- [x] 普通用户查看管理员创建的跨用户批次时保持只读，不提供整批恢复入口。
- [x] 批次恢复接口校验管理员权限，或校验普通用户仍拥有整批账号。
- [x] 批次记录跳转继续由签到记录接口按账号归属隔离。
- [x] 补充账号归属筛选、裁剪汇总和恢复权限测试。

## Answer

批次查询统一按账号归属裁剪：管理员可查看完整批次，普通用户只看到自己拥有的批次项和对应汇总。详情返回 `canResume`，跨用户批次对普通用户只读；恢复/重新入队仅允许管理员或仍拥有整批账号的创建者执行。
