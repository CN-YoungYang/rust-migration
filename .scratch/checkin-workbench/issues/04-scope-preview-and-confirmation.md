# 04：实现签到范围预览与批次确认

**要构建的内容：**

让管理员在签到工作台中选择账号并在执行前理解实际影响范围。系统需要把可执行账号、今日已签到、停用、达到上限和其他跳过项分开说明；管理员确认后锁定签到范围并创建异步签到批次。

Blocked by: 02, 03

Type: task
Status: resolved

- [x] 当前筛选结果中的可执行账号默认进入待执行选择，管理员可以取消部分账号。
- [x] 确认前显示实际账号数量、可执行数量、跳过数量及每个跳过账号的原因。
- [x] 已成功、已停用、达到每日上限、关闭重试或其他不符合条件的账号不会被前端绕过规则强行执行。
- [x] 确认后锁定签到范围快照；之后筛选条件或账号列表变化不影响已创建批次。
- [x] 批次详情能够看到实际签到范围，包括被跳过的账号及原因。
- [x] 同一签到账号已存在执行中批次时，显示冲突批次和当前进度，不重复创建执行操作。
- [x] 确认操作只创建异步批次并快速显示批次编号，不等待外部站点签到完成。
- [x] 创建请求超时或响应丢失后，前端可以重新查询或重试同一请求，不会重复创建批次。
- [x] 覆盖账号选择、预览、范围快照、冲突和 Cloudflare 断线场景的前端交互与后端行为测试。

## Answer

工作台默认选择服务端标记为可执行的账号，确认抽屉展示总数、执行数、跳过数和逐账号原因，取消选择后以快照创建异步批次。数据库约束保证执行中账号不会重复进入多个批次，冲突响应包含占用批次和进度；前端使用同一幂等标识恢复创建请求。
