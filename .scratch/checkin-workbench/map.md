# 签到工作台实现地图

## Notes

签到工作台围绕今日业务日期和用户数据范围，使用服务端持久化签到批次承接实际执行，前端通过短控制请求轮询进度，适配 Cloudflare 代理域名和低配服务器。

## 当前状态

- 实现状态：已完成签到工作台、持久化异步批次、范围预览、进度恢复、失败重试、响应式 UI 和按账号归属的权限隔离。
- 自动验证：Rust 120 项测试、前端 57 项测试、Rust 格式检查、前端生产构建和差异检查均已通过。
- 部署验收：待真实 Cloudflare 挂载域名环境执行浏览器人工验收；该事项只验证部署链路和视觉体验，不代表本地实现尚未完成。

## Decisions-so-far

- [01：统一批量签到业务语义](issues/01-unify-batch-semantics.md)：批量签到统一使用 `manual_batch`，服务端负责跳过规则和批次汇总。
- [02：实现 Cloudflare 安全的异步签到批次](issues/02-cloudflare-safe-async-batches.md)：批次范围与进度持久化，创建幂等，状态查询禁止缓存。
- [03：建立签到工作台首屏与账号队列](issues/03-workbench-overview-and-queue.md)：工作台成为默认页面，首屏指标和账号队列由聚合接口提供。
- [04：实现签到范围预览与批次确认](issues/04-scope-preview-and-confirmation.md)：确认时锁定范围快照，数据库约束阻止执行中账号重复入批次。
- [05：实现进度恢复、批次详情与结果导航](issues/05-progress-recovery-and-details.md)：凭批次编号恢复轮询，详情支持跳转签到记录。
- [06：失败处理、快捷操作与响应式 UI](issues/06-retry-actions-and-responsive-ui.md)：重试、行级快捷操作和桌面/移动响应式界面完成。
- [07：按签到账号归属隔离批次可见性](issues/07-account-scoped-batch-visibility.md)：普通用户只看自己的批次项，跨用户批次保持只读，恢复权限按整批账号归属校验。
- [管理员所属用户筛选修正](../../src/db/batches.rs)：管理员筛选所属用户时按批次范围内账号归属过滤，而不是按批次创建人过滤。

## Fog

- 第一阶段暂不提供服务端中途取消、暂停和服务重启自动续跑；等待状态提供经过权限校验的手动重新入队入口。
- 部署验收待在真实环境观察 Cloudflare 超时、断线恢复和移动端抽屉布局。
